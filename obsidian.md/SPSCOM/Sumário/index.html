Configurar como página inicial do Edge
  1. Salve este HTML em uma pasta definitiva e abra-o no Edge.
  2. Copie o endereço completo da barra, começando com file:///.
  3. No computador, abra Configurações → Iniciar, página inicial e novas guias. Em “Quando o Microsoft Edge é iniciado”, escolha abrir estas páginas e adicione o endereço copiado.
  4. Para o botão Página inicial, habilite-o e informe o mesmo endereço.

Nova Guia: a página de inicialização e o botão Página inicial não substituem a Nova Guia. A substituição costuma exigir uma extensão compatível, que também precisa aceitar arquivos locais.

No celular: o layout se adapta à tela, mas abrir HTML local e configurar a inicialização depende do sistema e da versão do Edge. Se o arquivo não abrir no navegador, use uma hospedagem privada. Não publique este sumário abertamente: ele contém links de trabalho.

O link DataService Ethernet exige acesso à rede interna ou VPN. Os serviços web podem solicitar autenticação. Esta página é uma cópia do arquivo original, sem sincronização automática com o Markdown.

As preferências ficam neste navegador quando o armazenamento local está disponível. Mover o HTML pode exigir configurar o cofre novamente.
